# skladActiv

**Учёт торговли и склада для малого бизнеса: свой склад на вашем компьютере, работа с телефона, интеграция с Ozon.**

Данные хранятся у вас, на вашем компьютере. Облака, абонентской платы и сторонних серверов нет. Компьютер с программой работает как сервер, а телефон и другие компьютеры подключаются к нему по Wi-Fi или из любой точки мира.

## Что умеет

**Склад и товары**
- Товары с артикулами, штрихкодами, закупочной ценой и минимальным остатком.
- Несколько складов, перемещения между ними, инвентаризация, приход и списание.
- Журнал всех движений. Остаток не уходит в минус.
- Сканер штрихкодов камерой телефона или обычным сканером.
- Список «Пора закупать» на главном экране.

**Продажи, закупки и деньги**
- Закупки у поставщиков и продажи клиентам: черновик, проведение, отмена с возвратом остатков.
- Платежи по документам, долги клиентов и поставщиков.
- Контрагенты, финансы, дашборд с графиками.
- Выгрузка в Excel/CSV и печать документов.

**Ozon**
- Подключение по Client-Id и Api-Key.
- Синхронизация товаров, остатков, заказов (FBS и FBO) и возвратов.
- Обратная отправка остатков в Ozon при изменении на складе. Защита от случайного обнуления.
- Поставки FBO и сверка принятого по акту.
- Чистая прибыль с учётом комиссий, логистики, возвратов и себестоимости: по дням, по товарам, с убыточными позициями.
- Выплаты на банковский счёт и сравнение с начислениями.
- Отчёт по покупателям: кто заказывает часто, а кто не забирает заказы.
- Журнал событий и оповещения о сбоях синхронизации.

**Безопасность и надёжность**
- Роли: администратор, менеджер, бухгалтер, продавец, кладовщик. Права проверяются на сервере.
- Автоматическая резервная копия раз в сутки, ручные копии, восстановление.
- Ограничение попыток входа, смена пароля.
- Данные не удаляются при обновлении программы.

## Как это устроено

| Что | Для чего |
|---|---|
| **skladActiv-Setup-X.exe** | Главный компьютер с Windows 10/11. Хранит данные и работает как сервер. Свой Python внутри, ничего ставить не нужно. |
| **skladActiv-Client-Setup-X.exe** | Второй компьютер с Windows, который подключается к главному. |
| **skladActiv-X.apk** | Телефон на Android. |

Главная программа живёт в трее возле часов. Если закрыть окно, сервер продолжает работать, поэтому телефон не отключается. Вместе с Windows она запускается сама.

Из интернета (не из домашней сети) можно подключаться через [Tailscale](https://tailscale.com): он ставится на компьютер и телефон и не требует настройки роутера.

## Установка

1. Скачайте последние файлы на странице **[Releases](../../releases/latest)**.
2. На главном компьютере запустите `skladActiv-Setup-X.exe`. На вопрос Windows «Разрешить внесение изменений?» нажмите **Да**.
3. На телефоне установите `skladActiv-X.apk` (разрешите установку из этого источника) и введите адрес сервера, который показан в программе на компьютере в разделе «Подключение».
4. При первом входе создайте администратора. Остальных сотрудников добавляйте по коду приглашения.

Данные хранятся в `C:\Users\<вы>\AppData\Roaming\DroneZoneStock\data`. Для резервной копии скопируйте эту папку.

## Обновления

Программа сама проверяет эту страницу и предлагает обновиться, когда выходит новая версия.
- **Компьютер:** окно «Доступна версия X» с кнопкой «Обновить сейчас». Установщик скачивается, проверяется контрольная сумма, делается копия базы, после чего программа перезапускается.
- **Телефон:** в приложении появляется плашка с кнопкой «Скачать и установить».
- Проверить вручную: значок в трее → «Проверить обновления».

Каждый выпуск содержит файл `SHA256SUMS.txt` с контрольными суммами.

## Требования

- Windows 10/11 (64-бит) для компьютера.
- Android 7 и новее для телефона.
- Для Ozon: ключ API из личного кабинета продавца (Настройки → API-ключи).
